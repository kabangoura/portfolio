projet-fil-rouge

Application de gestion et de planification de publications

Projet développé en trois versions successives, depuis un modèle de publications utilisé dans la console jusqu'à une interface de calendrier avec publications publiées et interactions utilisateur.

  • Technologies : Java, Maven, JavaFX, Jackson Databind et JSON.
  • Fonctionnalités : hiérarchie de classes, validation des publications, sérialisation polymorphique, sauvegarde d'un fichier JSON par publication et filtrage dans le calendrier.
  • Évolution : version 1 console, version 2 avec persistance JSON, version 3 avec interface calendrier.

Le-Jeu-du-Pendu

Jeu du pendu en C#

Application console permettant de jouer seul ou à deux, avec plusieurs niveaux de difficulté et un affichage progressif du pendu en ASCII.

  • Technologies : C#, .NET 9 et NUnit.
  • Fonctionnalités : filtrage des mots selon leur longueur, suivi des lettres proposées, mise à jour du mot masqué et validation des saisies.
  • Tests : recherche de lettres, victoire, gestion du pendu et validations principales.

Database_projet2

Application de gestion des ventes

Application Windows Forms connectée à SQL Server pour gérer des clients, des employés, des produits et des ventes.

  • Technologies : C#, .NET 8, Windows Forms, SQL Server et Microsoft.Data.SqlClient.
  • Fonctionnalités : opérations CRUD, clés primaires et étrangères, contraintes d'intégrité et connexion à une base relationnelle.
  • Base de données : vues BestSales, UrgentOrders, AverageClientAge, CityResearch et TotalSalesCommissions.
  • Automatisation : audit des ventes, notification des nouveaux produits et protection contre la suppression des tables avec des triggers.
